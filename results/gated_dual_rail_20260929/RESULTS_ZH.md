# 0/1 门控与双路共享读出的首轮结果

已实现并完成远程训练。**在本轮近等参数量、相同训练预算下，新结构没有优于
串联结构；三个测试层的 PPL 和局部拟合误差均略差。** 这不是十层/二十层
联合训练结果，也不能据此判定所有门控变体都无效。

## 结构与公平对照

详细公式见 [持续更新的设计文档第23节](../../experiments/pdnn_ffn/P_DNN_FFN_DESIGN_ZH.md)。

```text
x -> input p-bit z (0/1)
      ├─ Wg*z+bg -> temperature -> gate p-bit g (0/1)
      └─ Wv*z+bv -> temperature -> value p-bit v (0/1)

u_plus = g*v       -> Wd*u_plus  ─┐
u_minus = g*(1-v)  -> Wd*u_minus ─┴─ subtract + bd -> average N full paths
```

所有矩阵偏置均保留，隐藏偏置包含在交给 p-bit 的驱动值中。
p-bit 没有独立阈值参数；温度可学习。正负读出共享一个权重矩阵，偏置只加一次。
每次矩阵运算都接收真正的 0/1 状态，不把三值差分信号送回矩阵。

串联宽度4864、参数8,722,050；新结构宽度3242、参数8,721,879，差171。
这是近等参数量对照；并非等隐藏宽度或等运算量对照。新结构的稠密矩阵乘加项
每条路径多约33.3%，p-bit 状态数多约28.1%。软件仍用浮点权重和普通稠密运算，
未测试硬件二值专用电路。

## 实验协议

- Qwen2.5-0.5B Base，分别只替换 decoder layer 10、12、19（从0计数）。
- 两种结构均保留所有矩阵偏置，只学习温度，无额外 p-bit 阈值。
- WikiText-2 train 最后65,536个 token 作保留集，其余2,452,887个 token 用于训练。
- 每组2,000步 mean-field + 2,000步 N=4，batch=4、sequence=256；
  合计处理4,096,000 token，随机取窗可重复。训练 seed=0。
- 学习率依次3e-4、1e-4；AdamW weight_decay=0.01；
  损失 NMSE + 0.05*(1-cosine)，梯度裁剪1.0；不根据 test PPL 选 checkpoint。
- 使用最终 `student_sampled.pt`，完整 test 共299,078 token，计分299,077；
  max-length=2048、stride=1024，与既有基线一致。
- N=4 使用推理 seeds 0/1/2，表中 ± 是总体标准差；mean-field/N=16 使用 seed0。
  只有一个训练种子，这些标准差不代表训练重复实验的置信区间。
- 六组各用一张 RTX5090 并行运行。PyTorch2.7.1+cu128，BF16 autocast 训练；
  PPL 评估按既有流程将 student 转成 BF16。一次并行耗时不作为架构速度结论。

## 概率饱和度的发现

饱和定义为 `p<0.01` 或 `p>0.99`，使用原始 teacher FFN 的输入，
再采样 student 输入状态，统计隐藏驱动对应的概率。
这不是多层替换模型自身输入分布下的统计。

| 层 | 串联隐藏饱和率 | 门控 gate 饱和率 | 门控 value 饱和率 |
| --- | ---: | ---: | ---: |
| 10 | 19.496% | 1.944% | 0.043% |
| 12 | 21.280% | 2.860% | 0.102% |
| 19 | 36.974% | 22.709% | 2.266% |

**饱和率明显降低，质量却没有提高。** 低饱和率不是独立的质量目标：
非饱和概率也可能带来更多抽样噪声，而且全局均值接近0.5不代表每个节点都接近0.5。

给定一个输入二值状态，令 `s=g*(2v-1)`，两分支独立采样时有
`E[s]=p_g*(2*p_v-1)`、`Var(s)=p_g-p_g^2*(2*p_v-1)^2`。
这是解释噪声来源的单节点公式，不能忽略训练后权重而直接比较整个 FFN 噪声。
本轮差异也包含等参数量导致的宽度从4864缩到3242；尚未做等宽度或多训练种子消融。

去掉独立 p-bit 阈值的串联对照仍接近历史可学习阈值结果：
历史10/12/19层 N=4 为12.029378、12.067226、12.870613；
本轮为12.029757、12.066578、12.874141。
这支持继续使用“矩阵偏置 + 温度”的简单接口做实验，尚不证明多层联合模型也完全等效。

## 结论与后续边界

保留实现供后续研究，但本轮不直接启动十层/二十层替换。
若继续研究这条路线，先做等隐藏宽度的单层对照，区分宽度减少和门控本身的影响，
再考虑初始化和训练预算。当前证据不足以推荐它取代已有串联结构。
