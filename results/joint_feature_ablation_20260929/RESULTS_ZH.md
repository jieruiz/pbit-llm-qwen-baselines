# 四个 FFN：训练预算与中间输出蒸馏对照

日期：2026-09-29。Slurm 作业 1060 已完成（COMPLETED / ExitCode 0:0），单张 RTX 5090 总用时 40 分 05 秒。

结论：延长联合训练预算有效，四路径 PPL 从 13.153481 降到 12.981314（下降 0.172168，约 1.31%）。加入权重 0.1 的 FFN 中间输出蒸馏后为 12.980273，仅比相同预算对照低 0.001041，小于本轮推理种子的波动量级，且验证 PPL 更差、N=16 也略差；本轮没有观察到明确的额外收益。辅助组训练用时增加约 10.94%，暂不建议作为默认训练目标。

这不否定其他辅助权重、完整 block 状态匹配或独立训练重复的可能收益；本轮只测试了这一种 FFN 输出匹配方式。下一轮更值得优先检查逐层输入校准/归一化适配，而非把当前辅助损失直接推广到更多层。

本轮固定替换零基 decoder 层 10、11、12、13，采用 tanh ±1 全路径 P-DNN。三组共用四个局部训练初始化；每组联合训练 seed 0，四路径推理重复 seed 0/1/2。推理种子标准差不是独立训练不确定度。

## 两个预定比较

- 延长预算：long_3000 − reference_1000 = **-0.172168 PPL**。
- 相同预算下辅助损失：feature_3000 − long_3000 = **-0.001041 PPL**。
- 负差值表示改善，正差值表示退化。仅据本轮条件解释，不把一次训练的结果推广成方法的稳定优势。

## 协议、成本与限制

- 辅助 loss 匹配同一 token 上各 FFN 的连续输出，按每层 teacher 输出均方值归一化；两个网络分别使用自身隐藏状态。推理结构、参数量、温度和采样预算不变。
- 保留最后 65,536 个训练 token；每次验证固定抽取 64 个 256-token 窗口，计分 16,320 token，验证 RNG 固定为 12345。每 500 步按验证 CE/PPL 选最优，另保存 final。
- 3000 步组从同一初始权重使用新的优化器和对应总长度的 cosine 日程训练，不是对 1000 步 checkpoint 的延续。
- 完整 test 计分 299,077 token，window 2048、stride 1024。三组条件与 0.1 辅助权重事先确定。
- reference_1000 的三个四路径 PPL 与师弟原联合训练记录逐项复现；此次更大的验证覆盖仍选中第 1000 步。
- 四项 CPU 测试，以及短局部训练、带辅助 loss 的联合训练和整模型评估作为前置检查。
- 本次已核验 68 个归档结果文件及执行源码 SHA-256。原始清单路径以服务器目录为根，本文目录中的结果对应其 results/ 前缀。
- N=0 是 mean-field 代理，不是严格无限采样极限。尚未做独立训练种子复验、六层扩展或下游任务评测，也没有实际 p-bit 硬件速度/能耗测量。
