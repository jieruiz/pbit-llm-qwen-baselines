# 十层 P-DNN 逐通道编码校准预定实验

目标：在相同初始化与训练预算下，判断学习 p-bit 场的逐通道尺度及阈值，是否比固定编码进一步降低语言模型误差。日期：2026-09-29。

- 层集合：7、8、9、10、11、12、13、14、15、18（零基）。保持两个矩阵 896→4864→896、入口与隐藏矩阵输入 ±1、每个 FFN 只在最终连续读出后平均；训练及主要推理 N=4。
- 每个场从 `tanh(z)` 改为 `tanh(exp(a)*z+b)`；a、b 按通道学习，初始化为零。实际比例限于 [0.25,4]，偏置限于 [-4,4]。入口和隐藏两处均校准；每个 FFN 增加 11520 个参数，十层共 115200（约原 P-DNN 参数的 0.132%）。没有新增连续矩阵旁路。
- 同预算两组：fixed（原权重继续训练），calibrated（原权重及场尺度/阈值共同训练）。原权重 LR=1e-5、weight decay=0.01；新增参数 LR=3e-4、weight decay=0。均为 2000 步、50 步 warm-up 后 cosine、batch=1×256×4 accumulation、0.8 KL + 0.2 CE。校准组额外参数及不同参数组学习率是实验处理的一部分。
- 三个配对联合训练种子 0/1/2，每组从相同十层 checkpoint 开始并重置优化器。同种子共用文本批次与初始化 RNG；后续离散状态会因参数变化而分歧。
- 初始化：复用已经复现的四层联合 reference_1000 权重；重建其他六层局部蒸馏，再按原始协议重现十层 1000 步。开始正式对照前，要求 BF16 基线、分阶段初始化 PPL≈24.813126、十层 PPL≈19.223202 通过容差核对。文件哈希记录新制品身份，不假定重新序列化文件与原文件字节相同。
- 验证：保留最后 65536 train token，固定 64×256 窗口、固定 RNG=12345，每 500 步按验证 PPL 选 best，另存 final。检查 16320 个计分 token。完成六组训练后才评测候选 test。
- 测试：完整 WikiText-2 raw test，window=2048、stride=1024，299077 个计分 token。每个训练模型分别 N=4 推理种子 0/1/2，另 N=0 和 N=16 seed0。训练种子与推理种子分开统计。
- 预定目标：校准组三个训练种子各自推理均值的平均 PPL，较 fixed 至少降低 1%；至少 2/3 配对训练种子改善，且平均最佳验证 CE 同向改善。未满足时如实记录阴性或不确定结果；不根据 test 再调学习率或阈值。三次训练不能支持普遍性或硬件性能结论。
- 诊断：保留验证集上的入口/隐藏概率饱和比例（|mean|>0.99）、校准参数范围、teacher 原 FFN 在同一 student 输入下的局部 NMSE、输出 RMS 比。teacher 只参与独立记录与训练目标，不进入推理路径。局部 NMSE 不作为最终模型选择指标。
- 预检：FP32/BF16 零校准逐位等价、采样矩阵输入二值、末端平均、梯度到达、checkpoint 类型恢复与 RNG 保持；GPU 短训练、保存加载、整模型评测。所有计算通过一个个人 Slurm GPU 作业顺序执行。
- 同步：保留源代码与结果哈希，模型和数据不入 Git；核验后自动推送并创建 PR。不因负结果省略归档。
