# 注意力分支补充：Ising SoftMax 与 BoltzFormer 式筛选

发布分支：`pbit-attention-av-baseline`。实验日期：2026-10-06。
本补充保留原来的 `experiments/pbit_attention/` AV 采样基线，新增两个独立方案。
QK 随机乘法与分块缩放实验不属于本次补充；本轮也没有联合替换随机 FFN。

## 两种方法的区别与结果

| 方案 | 实际实现 | 2k PPL | 8k PPL |
| --- | --- | ---: | ---: |
| 原始 SDPA | 原模型对照 | 10.37356 | 9.41898 |
| Ising SoftMax | 强惩罚极限异步热浴动力学；预热 16、间隔 4、512 次读取 | 10.43017 ± 0.02268 | 9.46223 ± 0.02126 |
| BoltzFormer 式筛选 | 64-token 块均值摘要；`block_mean`、`ratio=0.5`、`rank=64` | 10.94290 ± 0.04148 | 9.55960 ± 0.00430 |

Ising 为 5 个推理种子，筛选为 3 个；± 表示种子总体标准差，不是数据集置信区间。
总计 140 项评估。所有方案仅替换 Qwen2.5-0.5B Base 的 24 层 decode 注意力，保留原始
FFN、权重、投影、RoPE 和精确 prefill，没有训练。2k/8k 各计分 4096/2048 个固定
WikiText-2 后缀 token，不能直接与完整测试集 PPL 或不同上下文横向比较。

Ising 实验保留驻留时间和有限读取间隔造成的相关性；不是先数值 softmax 再直接抽样。
完整 QK 仍保留。时间单位为理想单位 p-bit 更新时钟倒数，不是实际微秒。
有限惩罚与小规模异步更新另行验证，但大模型实验不是有限电导阵列或器件电路复现。
L 类需要 L-1 个 p-bit，每位逻辑连接度 L-2；统一互斥耦合的物理实现成本尚未验证。

BoltzFormer 式方案是免训练语言模型适配，不是原文已训练图像置信度网络的复现。
缓存 Key 块摘要并增量更新，以块概率生成 Bernoulli 候选掩码；候选内做精确注意力。
`ratio=0.5` 指抽样预算与块数之比，不是实际保留一半位置。没有重要性校正，筛选会
改变注意力目标。完整 QK 的 oracle 只用于分析筛选质量，不能用于声称节省 QK。

## KV 缓存：读取潜力不等于容量下降或已实现加速

概率采样的聚合形式为 `mean(V[index_t])`，可以仅读取采到的 V 行。当前参考代码仍用
密集 `weights @ V`，还没有实现稀疏 gather 内核；权重为零不会自动避免密集读取。
块筛选路径也仍计算密集参考 QK/PV。因此以下均为逻辑地址统计，不是实测显存流量。

| 方法 | 上下文 | 单头位置比例 | GQA 组地址并集约 |
| --- | ---: | ---: | ---: |
| Ising，预热16/间隔4/512次 | 2k | 4.62% | 18.86% |
| Ising，预热16/间隔4/512次 | 8k | 1.36% | 6.35% |
| 块均值筛选，预算0.5 | 2k | 20.97% | 55.6% |
| 块均值筛选，预算0.5 | 8k | 13.33% | 42.6% |

Ising 的位置比例是样本涉及的不同 V 地址；块筛选是整个候选块涉及的位置，二者语义
不同。多个 query 头共享 KV 时要看地址并集，不能直接把单头比例当作整体缓存读取率。
重复样本合并、GQA 组内读取复用、缓存行粒度和随机访问开销都会影响实际物理流量。

仅作理想估算：假设 K/V 等大、K 全读、V 按组内并集读取且忽略其他开销，8k Ising 的
总 KV 读取比例约为 `(1 + 0.063532) / 2 = 53.18%`。这不是实测加速比；完整 KV 仍需
保留，未来 query 可能访问本次未采到的位置。要降低容量还需压缩、淘汰或分层存储。
块筛选理论上可在选块后再读取候选 K/V，但当前实现尚未兑现该节省。
