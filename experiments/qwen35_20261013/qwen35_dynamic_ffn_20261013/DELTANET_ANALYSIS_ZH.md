# Qwen3.5-0.8B Gated DeltaNet：结构、计算量与随机计算候选

日期：2026-10-13。依据实际部署的 Transformers 5.19.0 源码、模型配置及 Gated Delta Networks 原论文。下文将官方算法、按尺寸推算和我们的研究建议分开说明。

**主要判断：DeltaNet 整层并不小，18 层在 2K 解码时约占 Transformer 主体 MAC 的 36%；但其主要成本是固定权重投影，递归状态核心相对小。因此可以先保留连续状态核心，把大投影矩阵作为后续随机计算目标，不必一次把整层都随机化。**

## 1. 在模型中的位置

24 个语言层按三层 Gated DeltaNet、一层完整门控注意力重复，合计 18 层 DeltaNet、6 层完整注意力；每个语言层还有一个 SwiGLU FFN。DeltaNet 是 token 混合器，其 FFN 已被当前全24层FFN替换方案覆盖，但 DeltaNet 内部算子目前保留官方计算。

完整注意力显式形成对历史 token 的 Softmax 权重，再对历史 V 求加权平均。DeltaNet 用固定尺寸的记忆矩阵概括历史，再根据当前 query 读取记忆；它没有可直接套用旧 PV 分类采样器的历史 Softmax 分布。

配置：[官方 config](https://huggingface.co/Qwen/Qwen3.5-0.8B/blob/main/config.json)。

## 2. 一层的结构与维度

输入 x 是该语言层 input RMSNorm 后的 1024 维向量。下表都按一个 token 说明。

| 分支／模块 | 维度或计算 | 用途 |
|---|---|---|
| in_proj_qkv | 1024→6144 | 产生三条各 2048 维的 Q/K/V 原始分支 |
| 短因果卷积 | 6144 通道，各通道独立，核长4 | 混合当前和最近三个位置，不是全通道相互连接 |
| 卷积后的 SiLU | 6144 元素 | 给 Q/K/V 添加非线性 |
| 分头 | Q/K/V 各16头，每头128维 | 每个头维护自己的关联记忆 |
| Q/K L2 归一化 | 每头128维 | 调整方向尺度，K 的长度接近1；Q还除以 √128 |
| in_proj_b | 1024→16，再 sigmoid | 每头一个写入强度 β |
| in_proj_a | 1024→16，再遗忘映射 | 每头一个记忆保留率 α |
| 状态矩阵 S | 每头128×128，16头 | 存储历史 key→value 关联 |
| 读取后 gated RMSNorm | 每头128维 | 规范读出幅度，并乘 SiLU(z) |
| in_proj_z | 1024→2048 | 提供上述输出门控 z，沿分支直接产生，不经过短卷积 |
| out_proj | 2048→1024 | 把16头读出送回残差主干 |

大矩阵投影均不带 bias。但遗忘映射有学习的 dt_bias，且 A_log 也是学习参数，因此“所有线性层不带偏置”不意味着整个 DeltaNet 没有偏置。

DeltaNet 的 gated RMSNorm 使用 **SiLU(z)**，与完整注意力的 **sigmoid 输出门控**不同。输出可写为 W_out[ u⊙SiLU(z) ]，其中 u 为带学习增益的逐头 RMSNorm 读出，因此这一输出门控与 FFN 的 SwiGLU 产品有直接关联。

实现：[Transformers Qwen3.5 源码](https://github.com/huggingface/transformers/blob/main/src/transformers/models/qwen3_5/modeling_qwen3_5.py)。

## 3. 记忆更新：五个容易理解的步骤

以下针对一个头，采用源码的 S∈R^(128×128)、key为行方向、value为列方向约定。论文可采用转置约定，数学等价。q/k 已经过上述归一化。

### 3.1 遗忘旧记忆

S̃ = α S_prev。

α接近1保留较多历史，α接近0快速遗忘。当前实现：

α = exp[−c·softplus(a+d)]，c=exp(A_log)>0，d=dt_bias。

因此 α∈(0,1]，FP32 中极端值可舍入到边界。β=sigmoid(b)，位于0～1。

### 3.2 先检查旧记忆对当前 key 的回答

v_hat = S̃ᵀ k。

它不是对全部历史 token 做 Softmax，而是在固定128×128矩阵上做矩阵向量乘。

### 3.3 计算“需要纠正多少”

δ = β (v − v_hat)。

这里有连续的带符号减法；它不只是两个非负概率做 AND。

### 3.4 写入纠正量

S_new = S̃ + k δᵀ。

kδᵀ是一个128×128外积，不是两个128×128矩阵相乘。纠正后的矩阵只提交为当前 token 的新状态一次。

若 β=1且 ||k||²=1，则 S_newᵀk=v：它把“当前 key 对应的答案”准确改成当前 value。β小于1时只做部分纠正。

### 3.5 用当前 query 读取更新后的记忆

o = S_newᵀ q。

所有头的读出随后经过 gated RMSNorm 和 out_proj，最后与语言层残差相加。

把更新合并，可写为：

S_new = α(I−βkkᵀ)S_prev + βkvᵀ。

所以名字中的 Delta 指“按预测误差纠正”，Gated 指“控制遗忘与写入”。它是一种关联记忆，不是把历史 K/V 全部存进去逐个查询。

原论文：[Gated Delta Networks，§3](https://arxiv.org/html/2412.06464v1#S3)。作者实现：[NVlabs/GatedDeltaNet](https://github.com/NVlabs/GatedDeltaNet)。

## 4. 预填充和解码不是完全相同的程序组织

逐 token 解码按上述递推更新，每头的状态尺寸不随上下文增长。训练或预填充一次输入很多 token 时，采用等价的分块并行算法；块内可能出现 QK 小矩阵、三角系统及块间扫描。不能因此说实现中“完全不存在 QK”，但它不是完整历史的 QK→Softmax→PV。

本报告操作数以直接递推解码为基准，适合讨论一种专用循环硬件。GPU FLA 预填充内核的实际操作数、临时张量和运行时间需要另行计量。当前部署采用 FLA 内核；PyTorch参考实现不代表最优GPU运行时间。

论文分块算法：[§3.2](https://arxiv.org/html/2412.06464v1#S3.SS2)，内核项目：[flash-linear-attention](https://github.com/fla-org/flash-linear-attention)。

## 5. 计算量到底大不大

MAC表示一次乘法加一次累加。以下是batch1、每个新解码token的架构估算。没有把一次普通乘法和一次MAC视为同成本；未计归一化、激活、Softmax、残差、控制和存储访问。

### 单个 DeltaNet 层

| 部分 | MAC/token |
|---|---:|
| QKV 投影 | 6291456 |
| z 投影 | 2097152 |
| a/b 两个小投影 | 32768 |
| 输出投影 | 2097152 |
| 固定投影合计 | **10518528** |
| 状态预测、外积写入、query读取 | **786432** |
| 短卷积 | 24576 |

另外有262144次状态衰减乘法，以及少量向量乘法/加减和非线性。预测及读取各约16×128×128 MAC，外积写入也是这个数量级，不是128³。

固定投影约占该层以上 MAC 的 **92.84%**。这一比例不是能耗占比，FP32状态运算和状态存储可能比INT8投影单次操作贵。

### 全模型对照：百万 MAC/token

| 部分 | 2K上下文解码 | 8K上下文解码 |
|---|---:|---:|
| 24层 FFN，三个矩阵 | 264.24 | 264.24 |
| 18层 DeltaNet 固定投影 | **189.33** | **189.33** |
| 18层 DeltaNet 状态读写核心 | **14.16** | **14.16** |
| 18层短卷积 | 0.44 | 0.44 |
| 6层完整注意力固定投影，包含查询门控投影 | 44.04 | 44.04 |
| 6层完整注意力 QK＋PV | 50.33 | 201.33 |
| Transformer主体合计 | 562.54 | 713.54 |
| 词表输出矩阵，单列 | 254.28 | 254.28 |

DeltaNet 状态衰减还有 **4.72百万 MUL/token**，未混入 MAC 列。主体不含词表输出矩阵。18层DeltaNet含投影/核心/卷积的MAC占主体约36.25%（2K）／28.58%（8K）；状态读写核心本身仅约2.52%／1.98%。

因此“整层都保留，因为它计算量很小”不准确；“保留递归核心，优先研究大矩阵”有充分操作数依据。不能直接从上述MAC比例推出功耗节省。

可复算数据：deltanet_operation_counts.json；生成程序：count_deltanet_ops.py。这些数值由实际模型维度推算，不是论文作者给出的功耗或实测GPU利用率。

## 6. 存储成本

每层状态16×128×128=262144元素。FP32每层1MiB，18层合计 **18MiB/序列**，与上下文长度无关。另有短卷积的最近4位置缓冲约0.84MiB（按BF16估算）。batch数增加时状态按序列复制。

但6层完整注意力仍需历史KV缓存，按BF16估算为24MiB（2K）／96MiB（8K），不包含框架预留和临时空间。因此模型不是“完全没有KV缓存”。

相对于此前Qwen2.5-0.5B，不能仅凭完整注意力从24层变6层就宣称KV缓存减到四分之一：新模型KV每头维度从64变256，抵消了层数下降；两者这部分KV缓存的每token字节数相同。新模型还增加了固定DeltaNet状态。相对于同样头维度的24层全注意力模型，混合布局才显著减少随上下文增长的KV。

保留连续状态仍需优化其驻留和读写：18MiB SRAM并不免费，外存访问可能显著影响能量；不能以MAC少直接忽略这部分。状态分块、运算融合、减少重复搬运和后续可验证的状态量化，是不改变概率算法的独立方向。

## 7. 哪些部分适合先引入随机计算

| 候选 | 数学及硬件特征 | 建议 |
|---|---|---|
| out_proj | 固定权重，输入为连续读出；不直接修改本层状态更新公式 | 首个候选，先少量层再18层 |
| 输出 RMSNorm(o)×SiLU(z) | 等于 u×z×sigmoid(z)，与现有FFN三流AND结构相近 | 可复用AND产品后接固定out_proj；保留RMSNorm |
| in_proj_z | 固定权重，产生输出门控分支 | 第二步加入，单独区分误差 |
| in_proj_qkv | 固定权重且成本最大；噪声直接进入卷积缓存、key方向和记忆写入 | 有价值，但应在out/z以后，做长度相关PPL和状态误差诊断 |
| in_proj_a/b | 18层合计仅0.59百万MAC，控制遗忘和写入 | 初期保持准确，节省小、敏感性可能大 |
| 短卷积、Q/K归一化、RMSNorm | 算术量较小，归一化关系到状态稳定性 | 初期保留 |
| 连续状态核心 | S是每个token修改的状态，不是固定模型权重 | 初期保持FP32；后续考虑专用定点或选择性更新 |

out/z/QKV三个大投影合计188.74百万MAC，覆盖DeltaNet上述MAC约92.6%；仅out_proj也有37.75百万MAC。可以共享现有“随机输入＋固定权重位平面AND＋准确计数”的模块，不必为整个DeltaNet另造全新矩阵体系。但连续到概率编码和计数读出仍有代价，是否节能需后续按统一硬件口径估算。

把S参与的矩阵向量乘也随机化，在数学上可以，但S是动态权重，无法直接照搬固定位平面常量优化；还要处理有符号数、双随机乘法、编码读写及状态噪声。这和之前固定权重实验的条件不同。

## 8. 可以用p-bit直接做写入门吗

β=sigmoid(b)，因此一个sigmoid型p-bit天然可以给出B∈{0,1}、P(B=1)=β。固定当前输入与旧状态时，令：

S_new = S̃ + B k(v−S̃ᵀk)ᵀ。

其条件期望等于原连续β更新。B=0的头可以跳过预测和外积写入，仍要遗忘及读出。它是一种“抽样写记忆”，不是历史V的分类抽样。

然而一次抽样产生完整跳写／不写，而原模型要求部分更新。后续RMSNorm及其它非线性使局部期望正确不能保证整个LLM输出无偏。连续记忆里保存的是一次实现，不是很多独立实现的均值。此方向应作为新的有噪声架构，需要试验或训练，不能据条件期望直接宣称等价加速。

α的映射不是一般的sigmoid：α=[sigmoid(−(a+d))]^c。仅c=1时可以直接用一个p-bit；c为正整数时独立p-bit的AND可表示幂，但模型中的c是任意学习的正实数，不能假定为整数。可研究按头查表或近似驱动，不过要计映射成本。

## 9. 为什么不能在每个采样周期都更新一次S

4096个采样周期是**同一个token的一次数值计算**，不是4096个语言token。若每个位周期都执行原状态递推，遗忘会重复应用，出现α^4096，并重复写入当前value，已经改变了原模型。

正确的数值模拟应固定该token的S_prev，统计同一更新的采样结果，在末尾只提交一次S_new，或者推导有明确等价性的微步算法。与FFN相比，这正是递归模块额外需要的时序约束。

## 10. 随机误差是否一定一直累积

不一定。固定精确驱动时，误差传播矩阵为A_t=α_t(I−β_t k_tk_tᵀ)。归一化k、0≤β≤1时，||A_t||₂≤α_t，存在衰减机制。当α接近1时，噪声仍可能长期保留；随机化Q/K、a/b或下游非线性时，分析更复杂。

所以“递归一定不稳定”和“局部无偏所以整网没问题”都不能直接成立。可按实际门控分布、状态误差、长上下文PPL判断。只用2K滑窗PPL时，每窗重置状态，不能验证262K上下文的误差积累。

原模型训练文本上的alpha/beta统计任务1254已完成，见results/deltanet_gates.json。alpha均值0.8659，37.62%观测大于0.999；beta均值0.3962。它只观察原模型，不替换、训练或跑基础任务。

## 11. 本次行动与后续顺序

动态尺度FFN对照已通过Slurm任务 **1246** 启动：INT8确定性对照一次；动态FFN和动态FFN＋PV512各三个种子，全部只计算完整WT2 PPL，不重新启动五项基础任务。

沿用旧成功版 streaming 协议：输入4096、有效输出3072、每256次更新、预热25%、每token每64通道动态max；概率使用连续参考值，并未新增N12比较器量化。它与此前固定尺度分阶段版本既有尺度差异也有时间组织差异，因此结果不能只归因于一个因素。

北京时间14:38快照，已完成seed0的完整WT2：INT8确定性对照15.651730；动态FFN **15.841271（比原始15.661098高约1.15%）**；动态FFN＋PV512 **15.924675（高约1.68%）**。它们都是完整297192计分token，不是中间进度PPL。此段为历史seed0快照；现已测齐，动态FFN均值15.840404，动态FFN＋PV均值15.923481。

建议优先顺序：先完成动态FFN质量对照；DeltaNet暂保留状态、卷积和归一化；然后单独试out_proj，再试输出三流AND及z投影，最后才考虑QKV投影。每一步保留准确a/b，记录相同PPL协议。记忆核心随机化或状态量化另立对照，不与固定大投影同时改，方便定位误差。
